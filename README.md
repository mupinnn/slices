# Slices

My intention for creating this project is to practice more on CSS and JavaScript (vanilla)
by slicing design into code; also to get my hand dirty with other stuff like setting up build tools and bundlers.

## Used Tools

- Turborepo
- GitHub Actions
- Astro
- Vite
- Prettier
- Plop
- Tailwind CSS
